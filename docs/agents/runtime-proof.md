# Runtime proof

Verify the exact surface touched by the task. Source changes, tests, installation, process health and live acceptance are separate proof boundaries. Record commands, immutable artifact paths, exact build/process/session identities and bounded pass/fail gates where applicable.

For browsers, check scoped OS process identity, CDP/route readiness and screenshots or DOM evidence as needed. Service status alone does not prove browser health. Preserve unknown exit attribution.

For event wakes, distinguish native event delivery and result consumption from scheduler acknowledgment and watchdog delivery. A watchdog must not manufacture event-consumed evidence. Early completion or a short Instant run does not prove active-chat idle-expiry protection.

Verify MCP wiring and installed services against their actual configuration, process and direct API/CLI readbacks when relevant. Report mismatches with documentation. Do not retry failed privileged operations or perform provider effects beyond current authorization.

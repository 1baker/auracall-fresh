# Domain docs

AuraCall uses a single domain authority: root `CONTEXT.md`. Read it before domain exploration and use its vocabulary in issues, hypotheses and proposals. Do not create a competing GLOSSARY.md or rename CONTEXT.md as part of skill setup.

Read applicable decisions in `docs/adr/` when present, and relevant `docs/dev/policies/`, plans and architecture documents. Missing ADR folders do not require scaffolding. Surface contradictions with existing decisions before changing them. The workspace packaging does not override the existing domain authority.

Read `docs/agents/codex-code-discovery.md` before structural exploration and `docs/agents/codex-stack.md` for operating rules.
